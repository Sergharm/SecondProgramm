# Чекпоинт 1. Демонстрация LinuxSandbox v0.1

В первом чекпоинте реализованы консольное меню, выбор и проверка файла, изолированный запуск комплектных образцов, сбор сетевых событий через strace, журнал сеанса и текстовый отчёт.

## Сценарий демонстрации

Запустите команды в обычном пользовательском терминале из каталога `CourseWork`.

```sh
cmake -S . -B build
cmake --build build
./build/LinuxSandbox
```

1. Выберите `./build/test_tcp` через пункт **1** и покажите свойства ELF через пункт **2**.
2. Запустите анализ через **3** и откройте события через **4**. Найдите успешный `connect` и последующий отказ `ECONNREFUSED` после закрытия слушающего сокета.
3. Откройте журнал через **5** и сохраните отчёт через **6**. Откройте текстовый файл по выведенному пути.
4. Выберите `./build/test_udp`, повторите анализ и покажите вызовы `sendto` и `recvfrom`.
5. Выберите `README.md` и покажите отказ при попытке запуска анализа через **3**.

Порты назначает ядро, поэтому их значения при каждом запуске могут отличаться.

## Скриншоты для отчёта

1. Успешная сборка и главное меню.
2. Сведения о выбранном TCP-образце.
3. TCP-события с успешным и неуспешным `connect`.
4. UDP-события с `sendto` и `recvfrom`.
5. Журнал сеанса и сообщение с путём сохранённого отчёта.
6. Открытый текстовый отчёт с сетевыми событиями.
7. Отказ в запуске файла вне списка разрешённых образцов.
