# Сборка и контрольные испытания LinuxSandbox v0.1

Проверка выполнена 28.11.2026 на рабочей копии ревизии `5bdd53b`. Среда — Kali Linux 2026.1 x86_64, Oracle VirtualBox, GCC 15.2.0, CMake 4.3.4, Bubblewrap 0.13.1 и strace 7.3. Динамические запуски выполнены обычным пользователем. Исходные файлы и правила запуска разрешённых образцов сохранены.

```sh
cmake -S . -B build-progress -DCMAKE_BUILD_TYPE=Release
cmake --build build-progress --parallel 2
ctest --test-dir build-progress -N
```

Цели `LinuxSandbox`, `test_tcp` и `test_udp` собраны без предупреждений с C++17 и флагами `-Wall -Wextra -Wpedantic`. CTest сообщил о нуле зарегистрированных тестов. Два образца проверены через штатное меню приложения. Рабочие файлы и протоколы запуска находятся в локальном каталоге `build-progress/`, исключённом из Git.

Пятисекундный предел подтверждён по исходным файлам Sandbox.cpp и ProcessManager.cpp. Штатный комплект содержит два коротких контрольных примера. Отдельный прогон с принудительной задержкой для этого документа не выполнялся.

## Пределы текущей версии

Запуск допускается для двух штатных образцов данной сборки. Анализ синхронный. События извлекаются из распознанных завершённых строк сетевой трассы после выполнения. Полноценный захват пакетов и мониторинг файловых операций отсутствуют. Журнал хранится в памяти сеанса. Формат сохранения — TXT. Графический интерфейс и экспорт JSON относятся к плану развития.

## Проверка материалов

Титульный лист, введение, порядок иллюстраций и нижняя нумерация сверены по всем 16 страницам образца Косолапа из каталога `docs/templates/`. Итоговый PDF содержит 15 страниц А4, 23 рисунка и занимает 3,09 МБ. В текст PDF встроен Times New Roman. На первой странице номер скрыт, далее номера 2–15 выведены по центру нижнего поля. Комплект содержит 26 снимков, включая фрагменты редактора, и две отдельные схемы с исходниками DOT.

PDF открыт, отрисован и визуально проверен постранично. DOCX открыт как редактируемый пакет. Проверены стиль основного текста, состав рисунков, поля и разметка нумерации. Визуальная проверка относится к PDF.
