# Результаты проверок LinuxSandbox v0.1

Дата проверки — 28.11.2026. Среда — Kali Linux 2026.1 x86_64, GCC 15.2.0, CMake 4.3.4, Bubblewrap 0.13.1 и strace 7.3, обычный пользователь. Сборка через CMake в `build-docs/check`, конфигурация Release. Все образцы принадлежат этому комплекту. Операции обмена выполнялись внутри Bubblewrap через IPv4 loopback. Отчёты и сырые протоколы хранятся локально в игнорируемом каталоге сборки.

| Идентификатор | Название | Ожидаемый результат | Фактический результат | Статус | Замечания |

| С01 | Конфигурация и сборка | Компилируются три цели C++17 с указанными предупреждениями. | `LinuxSandbox`, `test_tcp`, `test_udp` собраны, предупреждений нет. В сборочных параметрах `-std=c++17 -Wall -Wextra -Wpedantic`. | пройдено | `cmake -S . -B build-docs/check -DCMAKE_BUILD_TYPE=Release` и `cmake --build build-docs/check --parallel 2`. |

Снимки нумеруются по отчёту первого чекпоинта. Протокол не переносит результаты из образцов оформления. Номера портов, PID и имена отчётов относятся к конкретному тестовому сеансу.
