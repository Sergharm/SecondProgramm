# LinuxSandbox v0.1

Учебный прототип динамического анализа под Linux на C++17. Русскоязычное консольное меню показывает сведения о выбранном файле, а для комплектных программ собирает сетевые системные вызовы, журнал сеанса и текстовый отчёт.

## Зависимости

- Kali Linux 2026.1 x86_64 или совместимый Linux с каталогами системных библиотек в `/usr/lib` и `/usr/lib64`.
- Компилятор с поддержкой C++17, CMake 3.16 или новее и средство сборки, например Make.
- Bubblewrap и strace в `/usr/bin`. В Debian и Kali пакеты называются `bubblewrap` и `strace`.
- Поддержка создания пространств имён пользователя, сети и процессов обычным пользователем. Для анализа запускайте программу из обычного пользовательского терминала.

## Сборка и запуск

Из каталога `CourseWork` выполните:

```sh
cmake -S . -B build
cmake --build build
./build/LinuxSandbox
```

Выберите пункт **1** и введите `./build/test_tcp` или `./build/test_udp`. Пункт **2** покажет путь, тип, размер и доступ на исполнение. Запустите анализ пунктом **3**, откройте события пунктом **4**, журнал пунктом **5** и сохраните отчёт пунктом **6**. Файлы отчётов появятся в `reports/` относительно текущего каталога.

## Изоляция и ограничения

- Запуск разрешён только двум бинарникам из той же сборки, что и LinuxSandbox. Программа сверяет содержимое выбранного бинарника и передаёт в Bubblewrap копию встроенного образца.
- Bubblewrap создаёт отдельное сетевое пространство имён. Комплектные тесты используют `127.0.0.1` с портами, назначенными ядром. Ошибка настройки изоляции прерывает анализ до запуска образца.
- strace наблюдает сетевые вызовы внутри изолированной среды. События содержат PID внутри неё и доступные сведения о протоколе, IP, порте и результате. Пустые поля означают, что этих сведений в трассе не было.
- На запуск и анализ отведено 5 секунд. Журнал хранится в памяти до выхода. Сохранённый отчёт включает события последнего анализа и журнал текущего сеанса на момент сохранения.
- Прототип предназначен для комплектных учебных образцов. Для анализа реального вредоносного ПО необходима специализированная среда.
