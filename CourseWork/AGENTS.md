# Работа над LinuxSandbox

- Создавай и редактируй файлы только внутри `CourseWork`. Используй существующий Git-репозиторий. Для `git push` требуется подтверждение пользователя.
- Сохраняй C++17, CMake и флаги `-Wall -Wextra -Wpedantic`. Используй английские имена в коде и русские комментарии и сообщения интерфейса.
- Поддерживай независимость ядра от консольного и будущего графического интерфейса.
- Для динамических проверок используй только комплектные безопасные тесты в Bubblewrap от обычного пользователя с отдельным сетевым пространством имён и loopback. При сбое изоляции прекращай запуск.
- Фиксируй фактические результаты проверки и ограничения в `PROGRESS.md`. Исключай сборку, отчёты, трассировки и секреты из Git.
