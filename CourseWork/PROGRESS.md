# Состояние LinuxSandbox v0.1

## Чекпоинт 1

Готовы консольное меню, проверка пути и свойств файла, проверка содержимого комплектных образцов, запуск через Bubblewrap, сетевой мониторинг strace, журнал сеанса и текстовые отчёты. Сборка использует C++17 и флаги `-Wall -Wextra -Wpedantic`.

## Проверки от 28 ноября 2026 года

Среда проверки — Kali Linux 2026.1 x86_64, GCC 15.2.0, CMake 4.3.4, Bubblewrap 0.13.1 и strace 7.3.

| Проверка | Наблюдаемый результат |
| --- | --- |
| Сборка через CMake | LinuxSandbox и оба образца собраны без предупреждений. |
| Меню и свойства файла | Валидный путь открыл свойства ELF. Пустой или отсутствующий путь, каталог и некорректная команда обработаны. EOF завершил сеанс. |
| Ограничение запуска | README и подменённая копия `test_tcp` с изменённым байтом отклонены. |
| Сетевое пространство имён | В отдельной проверке Bubblewrap в `/proc/net/dev` обнаружен только интерфейс `lo`. |
| TCP через меню | 11 событий. Зафиксированы успешный `connect`, обмен по loopback и последующий отказ `ECONNREFUSED`. |
| UDP через меню | 6 событий, включая `sendto` и `recvfrom` по loopback. |
| Журнал и отчёт | Оба анализа сохранили текстовые отчёты с журналом и сетевыми событиями. Права файлов — `0600`. |
| Тайм-аут | При диагностической задержке входа в `socket` через strace модуль ProcessManager остановил Bubblewrap примерно через 5,02 секунды. Код завершения — 137. |
| Сбой изоляции | Под ограничениями среды Codex Bubblewrap получил `Operation not permitted` при настройке loopback. LinuxSandbox прекратил анализ с нулём событий. |

Рабочие проверки Bubblewrap выполнены вне ограничений среды Codex от обычного пользователя. Образцы оставались в отдельных пространствах имён без внешнего сетевого доступа.

## Текущие ограничения и следующий этап

Запуск ограничен двумя тестами из сборки. Мониторинг охватывает завершённые сетевые системные вызовы. Журнал живёт в пределах сеанса и сохраняется вместе с отчётом. Следующий чекпоинт добавит наблюдение за дочерними процессами и файловыми операциями, расширит сетевой анализ и добавит JSON-отчёты. [План развития](docs/roadmap.md)
